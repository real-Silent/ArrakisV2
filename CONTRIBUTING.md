# Contribution Policy

**Found a bug or a feature that is broken?**
Create an issue and follow the rules below.

1. Before creating an issue, make sure it hasn't already been reported.
2. Please use the issue format below.
3. Don't create useless or spam issues.

## Issue Format

[FileName.cs]
Bug or Broken Feature
Description and how to recreate it

---

**Want to contribute to Arrakis?**

## How to Make a Pull Request

1. Fork the menu and open the `.sln` file.
2. Fix, add, or remove the feature you want to contribute.
3. Please don't use AI code, you should atleast know how to code in C#.
4. Make sure your changes work before submitting a pull request.
5. Explain what you changed in your pull request.

> If we don't think your contribution is worth adding, we may decline the pull request.

Thank you for contributing to Arrakis!
